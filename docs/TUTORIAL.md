## 1. 快速开始

### 打开客服系统

浏览器访问：**`http://你的服务器IP`**（本地开发用 `http://localhost:5173`）

你会看到两个入口：

| 页面 | 地址 | 用途 |
|------|------|------|
| 用户聊天 | `/` | 顾客使用的聊天窗口 |
| 管理后台 | `/admin` | 店主/客服管理一切 |

### 切换到你的语言

页面右上角有语言选择器，支持：

🇨🇳 中文 · 🇺🇸 English · 🇯🇵 日本語 · 🇰🇷 한국어 · 🇫🇷 Français · 🇪🇸 Español · 🇩🇪 Deutsch

切换后，界面文字和AI回复都会变成对应语言。

## 2. 管理后台总览

访问 `/admin`，左侧菜单包含所有功能：

### 数据看板

显示四大指标卡片 + 意图分布饼图 + 每日对话趋势折线图。一眼看清客服运营状况。

| 指标 | 含义 |
|------|------|
| 总会话数 | 累计对话数量 |
| 转人工率 | 触发人工客服的对话占比 |
| 满意度 | 知识库匹配成功率 |
| 知识条目 | 已发布的知识库条目数量 |

### API配置

首次使用需要配置 AI 引擎的 API 密钥：

1. 进入 `管理后台 → API配置`
2. 填入你的 DeepSeek API Key（在 [platform.deepseek.com](https://platform.deepseek.com) 获取）
3. 保存后即刻生效

> 💡 不填 API Key 也可以使用，只是 AI 回复会退化为知识库关键词匹配。

## 3. 知识库

知识库是 AI 的"大脑"。你在这里告诉 AI：顾客问什么，该怎么答。

### 添加一条知识

1. 进入 `管理后台 → 知识库管理`
2. 点击右上角 **新建** 按钮
3. 填写：

| 字段 | 说明 | 示例 |
|------|------|------|
| 问题 | 顾客可能问什么 | "多久能发货" |
| 答案 | AI该怎么回答 | "当天10点前下单当天发货，默认中通快递，2-5天送达" |
| 分类 | 归类方便管理 | "物流配送" |
| 状态 | 发布后生效 | 选择"已发布" |

4. 点击保存

### 知识库建议

- **覆盖面要广**：发货时间、退换货政策、产品材质、价格区间等常见问题都要覆盖
- **答案要简洁**：顾客不喜欢长篇大论，3-5句话说清楚即可
- **分类要清晰**：物流配送、退换货、产品咨询、支付问题等分类管理

## 4. 店铺画像

店铺画像让 AI "认识"你的店铺，回复时自动带上店铺信息。

### 填写店铺画像

进入 `管理后台 → 店铺画像`，填写以下信息：

| 字段 | 说明 |
|------|------|
| 店铺名称 | 比如"鑫隆五金" |
| 主营产品 | 比如"工业级五金工具、电动工具、紧固件" |
| 营业时间 | 比如"工作日 9:00-18:00" |
| 联系方式 | 电话/邮箱 |
| 物流配送 | 发货规则、快递公司、时效 |
| 退换货政策 | 退换条件、流程 |
| 沟通风格 | 正式 / 亲切 / 专业 |
| 开场白模板 | AI第一句话的参考 |

> 💡 店铺画像填得越详细，AI 回答越精准。特别是物流和退换货政策，是顾客最常问的。

## 5. 人工客服

AI 搞不定的问题，自动转给你来处理。

### 触发条件

顾客发送以下关键词会自动转人工：
- 中文："转人工"、"人工客服"、"投诉"
- English："Transfer to human"、"human agent"
- 日本語："オペレーター"
- 其他语言同样支持

### 管理员操作流程

1. 顾客点"转人工客服"按钮 → 进入等待队列
2. 你进入 `管理后台 → 人工客服`
3. 左侧列表看到等待中的会话，会标注客户来源语言（🇺🇸 🇯🇵 🇨🇳）
4. 点击会话，再点 **接入** 按钮
5. 开始实时对话
6. 结束后点 **结束会话** 或让顾客自己点

> 💡 顾客端也有"结束会话"按钮，可以主动挂断。

## 6. 多平台接入

除了自有聊天窗口，还可以接入 Ozon、Shopee 等电商平台的买家消息。

### Ozon 接入

1. 进入 `管理后台 → 平台管理 → 凭证配置`
2. 选择 Ozon，填入 Client-Id 和 Api-Key
3. 保存后系统会自动拉取 Ozon 买家消息
4. 在 `Ozon聊天` 页面查看所有 Ozon 聊天记录

> ⚠️ Ozon API 分为基础权限和 Premium 权限。基础权限只能**读取**消息（不能回复）。想通过 API 回复需要 Premium 订阅。我们提供了浏览器插件来绕过这个限制。

## 7. 浏览器插件

安装了浏览器插件后，在 Ozon 卖家后台页面会自动出现 🤖 浮动按钮，点击即可生成 AI 回复。

### 安装方法

1. 打开 Chrome 浏览器，地址栏输入 `chrome://extensions`
2. 打开右上角 **开发者模式** 开关
3. 点击 **加载已解压的扩展程序**
4. 选择项目中的 `chrome-extension` 文件夹
5. 完成！打开 `seller.ozon.ru` 即可看到右下角的 AI 按钮

### 使用方法

1. 登录 Ozon 卖家后台，进入消息页面
2. 点击买家消息进入聊天
3. 点击右下角浮动按钮
4. 插件自动分析买家消息并生成回复文案
5. 你可以直接复制粘贴到 Ozon 输入框发送

## 8. 常见问题

### Q: 为什么AI回复是中文，英文界面也没用？

检查两件事：①右上角语言是否切换了；②后台 API 配置里有没有填 API Key。没有 API Key 时 AI 只能从知识库匹配，知识库是中文字段就会回中文。

### Q: 转人工按钮点了没反应？

确认后端服务正常运行（访问 `/health` 看到 `{"status":"ok"}`）。如果后端挂了，重启 `customer-service` 服务。

### Q: 怎么部署到自己服务器？

参考项目 `deploy/` 目录下的脚本：
```bash
bash deploy/setup-server.sh <仓库地址> <webhook密钥> <DeepSeek_API_Key>
```

### Q: 支持哪些AI引擎？

默认使用 DeepSeek。你可以通过 API 配置页面修改为任何兼容 OpenAI 接口的模型，比如通义千问、GPT-4 等。

### Q: 数据存在哪里？

所有数据存储在 SQLite 数据库文件 `backend/data/customer_service.db`。定期备份这个文件即可。
